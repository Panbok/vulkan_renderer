# Bitmap Font Loader Design Document

> **Current boundary.** The bitmap-font loader ships, but this document retains
> planned code and an unchecked historical checklist. Treat the loader sources
> as the API and behavior authority.

## Overview

This document describes the implementation design for the **Bitmap Font Loader** in the VKR renderer. The loader parses BMFont text format (`.fnt`) files, loads associated atlas textures, and produces `VkrFont` resources that integrate with the text rendering system.

**Target Files:**
- Implementation: `lib/src/renderer/resources/loaders/bitmap_font_loader.c`
- Header: `lib/src/renderer/resources/loaders/bitmap_font_loader.h`
- Font configs: `assets/fonts/*.fnt`
- Font textures: `assets/textures/<font>_<page>.png`

---

## Input File Format: BMFont Text Format

The loader parses the **BMFont text format** (`.fnt` extension). This is a well-documented format generated by tools like BMFont, Hiero, or similar bitmap font generators.

### File Structure

```
info face="FontName" size=21 bold=0 italic=0 charset="" unicode=1 stretchH=100 smooth=1 aa=1 padding=0,0,0,0 spacing=1,1 outline=0
common lineHeight=20 base=17 scaleW=128 scaleH=128 pages=1 packed=0 alphaChnl=1 redChnl=0 greenChnl=0 blueChnl=0
page id=0 file="FontName_0.png"
chars count=96
char id=32   x=36    y=29    width=3     height=1     xoffset=-1    yoffset=19    xadvance=10    page=0  chnl=15
char id=65   x=47    y=16    width=10    height=12    xoffset=0     yoffset=5     xadvance=10    page=0  chnl=15
...
kernings count=0
```

### Line Types to Parse

| Line Type | Fields | Purpose |
|-----------|--------|---------|
| `info` | `face`, `size`, `bold`, `italic`, `unicode`, `padding`, `spacing`, `outline` | Font metadata and style info |
| `common` | `lineHeight`, `base`, `scaleW`, `scaleH`, `pages`, `packed`, channel info | Global metrics and atlas dimensions |
| `page` | `id`, `file` | Texture page file mapping |
| `chars` | `count` | Total character count (optional, for allocation hint) |
| `char` | `id`, `x`, `y`, `width`, `height`, `xoffset`, `yoffset`, `xadvance`, `page`, `chnl` | Individual glyph data |
| `kernings` | `count` | Kerning pair count (optional) |
| `kerning` | `first`, `second`, `amount` | Kerning pair adjustment |

## Data Structures

### Existing Types (in `vkr_resources.h`)

```c
// Font handle for referencing loaded fonts
typedef struct VkrFontHandle {
  uint32_t id;
  uint32_t generation;
} VkrFontHandle;

// Individual glyph metrics and UV coordinates
typedef struct VkrFontGlyph {
  uint32_t codepoint;  // Unicode codepoint (char id in .fnt)
  uint16_t x, y;       // Position in atlas
  uint16_t width, height;
  int16_t x_offset, y_offset;
  int16_t x_advance;
  uint8_t page_id;
} VkrFontGlyph;

// Kerning pair adjustment
typedef struct VkrFontKerning {
  uint32_t codepoint_0;  // first
  uint32_t codepoint_1;  // second
  int16_t amount;
} VkrFontKerning;

// Complete font resource
typedef struct VkrFont {
  uint32_t id, generation;
  VkrFontType type;          // VKR_FONT_TYPE_BITMAP
  char face[256];            // Font face name
  uint32_t size;             // Font size in pixels
  int32_t line_height;       // lineHeight from common
  int32_t baseline;          // base from common
  int32_t ascent, descent;   // Computed from baseline and line_height
  int32_t atlas_size_x, atlas_size_y;  // scaleW, scaleH
  VkrTextureHandle atlas;    // Loaded atlas texture
  Array_VkrFontGlyph glyphs;
  Array_VkrFontKerning kernings;
  float32_t tab_x_advance;   // Computed: 4 * space_advance
} VkrFont;

// Page reference for multi-page fonts
typedef struct VkrBitmapFontPage {
  uint8_t id;
  char file[256];
} VkrBitmapFontPage;
```

## Implementation Plan

### Phase 1: File Type Detection

```c
typedef enum VkrBitmapFontFileType {
  VKR_BITMAP_FONT_FILE_TYPE_NOT_FOUND,
  VKR_BITMAP_FONT_FILE_TYPE_FNT,      // Text format (target)
  VKR_BITMAP_FONT_FILE_TYPE_VKF       // Binary cache (future)
} VkrBitmapFontFileType;

vkr_internal VkrBitmapFontFileType
vkr_bitmap_font_detect_file_type(String8 path);
```

**Logic:**
1. Check if file exists
2. Check extension (`.fnt` or `.vkf`)
3. Return appropriate type

### Phase 2: Text Parser

```c
vkr_internal bool8_t
vkr_bitmap_font_parse_fnt(VkrBitmapFontParseState *state, String8 file_path);
```

**Parsing Steps:**

1. **Read entire file into memory** (using `file_read_string`)

2. **Line-by-line iteration:**
   ```c
   while (offset < file_str.length) {
     String8 line = extract_line(file_str, &offset);
     string8_trim(&line);
     if (line.length == 0 || line.str[0] == '#') continue;

     if (vkr_string8_starts_with(&line, "info")) {
       parse_info_line(state, line);
     } else if (vkr_string8_starts_with(&line, "common")) {
       parse_common_line(state, line);
     } else if (vkr_string8_starts_with(&line, "page")) {
       parse_page_line(state, line);
     } else if (vkr_string8_starts_with(&line, "char ")) {
       parse_char_line(state, line);
     } else if (vkr_string8_starts_with(&line, "kerning ")) {
       parse_kerning_line(state, line);
     }
   }
   ```

3. **Key-value parsing helper:**
   ```c
   // Parse "key=value" pairs from a line
   vkr_internal bool8_t
   vkr_bitmap_font_parse_key_value(String8 line, const char *key, String8 *out_value);

   // Parse quoted string: face="Ubuntu Mono"
   vkr_internal bool8_t
   vkr_bitmap_font_parse_quoted_string(String8 line, const char *key, String8 *out_value);

   // Parse integer: size=21
   vkr_internal bool8_t
   vkr_bitmap_font_parse_int(String8 line, const char *key, int32_t *out_value);
   ```

### Phase 3: Line Parsers

#### Info Line Parser
```c
vkr_internal bool8_t
vkr_bitmap_font_parse_info(VkrBitmapFontParseState *state, String8 line);
```

Extract:
- `face` (quoted string) → `state->face_name`
- `size` (int) → `state->font_size`
- `unicode` (int, 0 or 1) → `state->is_unicode`
- `bold`, `italic` (int) → stored but not critical
- `padding` (4 ints: top,right,bottom,left) → optional
- `spacing` (2 ints: horizontal,vertical) → optional

#### Common Line Parser
```c
vkr_internal bool8_t
vkr_bitmap_font_parse_common(VkrBitmapFontParseState *state, String8 line);
```

Extract:
- `lineHeight` (int) → `state->line_height`
- `base` (int) → `state->baseline`
- `scaleW` (int) → `state->scale_w`
- `scaleH` (int) → `state->scale_h`
- `pages` (int) → `state->page_count`

#### Page Line Parser
```c
vkr_internal bool8_t
vkr_bitmap_font_parse_page(VkrBitmapFontParseState *state, String8 line);
```

Extract:
- `id` (int) → `page.id`
- `file` (quoted string) → `page.file`

Push to `state->pages` vector.

#### Char Line Parser
```c
vkr_internal bool8_t
vkr_bitmap_font_parse_char(VkrBitmapFontParseState *state, String8 line);
```

Extract all fields and create `VkrFontGlyph`:
- `id` → `glyph.codepoint`
- `x`, `y` → `glyph.x`, `glyph.y`
- `width`, `height` → `glyph.width`, `glyph.height`
- `xoffset`, `yoffset` → `glyph.x_offset`, `glyph.y_offset`
- `xadvance` → `glyph.x_advance`
- `page` → `glyph.page_id`

Push to `state->glyphs` vector.

#### Kerning Line Parser
```c
vkr_internal bool8_t
vkr_bitmap_font_parse_kerning(VkrBitmapFontParseState *state, String8 line);
```

Extract:
- `first` → `kerning.codepoint_0`
- `second` → `kerning.codepoint_1`
- `amount` → `kerning.amount`

Push to `state->kernings` vector.

### Phase 4: Texture Loading (via Resource System)

```c
vkr_internal bool8_t
vkr_bitmap_font_load_atlas(
  VkrBitmapFontParseState *state,
  VkrAllocator *temp_alloc,
  VkrTextureHandle *out_atlas);
```

**Logic:**
1. For single-page fonts (`page_count == 1`):
   - Construct texture path: `assets/textures/<page.file>`
   - Use `vkr_resource_system_load(VKR_RESOURCE_TYPE_TEXTURE, ...)` to load
   - Extract handle from `VkrResourceHandleInfo.as.texture`
   - Store handle in `out_atlas`

2. For multi-page fonts (future enhancement):
   - Collect all page texture paths
   - Use `vkr_resource_system_load_batch(VKR_RESOURCE_TYPE_TEXTURE, ...)`
   - Store as texture array or multiple handles

**Path Resolution:**
```c
// .fnt file: assets/fonts/UbuntuMono21px.fnt
// page file: "UbuntuMono21px_0.png"
// Result:    assets/textures/UbuntuMono21px_0.png
String8 texture_path = string8_create_formatted(
    allocator, "assets/textures/%s", page.file);
```

**Implementation:**
```c
vkr_internal bool8_t
vkr_bitmap_font_load_atlas(
  VkrBitmapFontParseState *state,
  VkrAllocator *temp_alloc,
  VkrTextureHandle *out_atlas) {

  if (state->pages.length == 0) {
    log_error("BitmapFontLoader: no pages defined");
    return false_v;
  }

  // Get first page (single-page fonts)
  VkrBitmapFontPage *page = vector_get_VkrBitmapFontPage(&state->pages, 0);

  // Construct texture path and store for later unloading
  state->atlas_path = string8_create_formatted(
      state->load_allocator, "assets/textures/%s", page->file);

  // Load via resource system (NOT texture system directly)
  VkrResourceHandleInfo texture_info;
  VkrRendererError tex_error;
  if (!vkr_resource_system_load(
        VKR_RESOURCE_TYPE_TEXTURE,
        state->atlas_path,
        temp_alloc,
        &texture_info,
        &tex_error)) {
    log_error("BitmapFontLoader: failed to load atlas '%.*s': %s",
              (int32_t)state->atlas_path.length, state->atlas_path.str,
              vkr_renderer_get_error_string(tex_error).str);
    return false_v;
  }

  *out_atlas = texture_info.as.texture;
  return true_v;
}
```

### Phase 5: Font Construction

```c
vkr_internal bool8_t
vkr_bitmap_font_build_result(
  VkrBitmapFontParseState *state,
  VkrTextureHandle atlas,
  VkrFont *out_font);
```

**Steps:**
1. Copy face name to `out_font->face`
2. Set `out_font->type = VKR_FONT_TYPE_BITMAP`
3. Copy metrics: `size`, `line_height`, `baseline`, `atlas_size_x/y`
4. Compute `ascent` and `descent`:
   ```c
   out_font->ascent = state->baseline;
   out_font->descent = state->line_height - state->baseline;
   ```
5. Convert glyph vector to array
6. Convert kerning vector to array
7. Set atlas handle
8. Compute `tab_x_advance`:
   ```c
   VkrFontGlyph *space = find_glyph_by_codepoint(out_font, 32);
   out_font->tab_x_advance = space ? space->x_advance * 4.0f : out_font->size * 2.0f;
   ```

### Phase 6: Resource Loader Callbacks

#### can_load
```c
vkr_internal bool8_t
vkr_bitmap_font_loader_can_load(VkrResourceLoader *self, String8 name) {
  // Check for .fnt extension
  for (uint64_t i = name.length; i > 0; --i) {
    if (name.str[i - 1] == '.') {
      String8 ext = string8_substring(&name, i, name.length);
      String8 fnt_ext = string8_lit("fnt");
      return string8_equalsi(&ext, &fnt_ext);
    }
  }
  return false_v;
}
```

#### load
```c
vkr_internal bool8_t
vkr_bitmap_font_loader_load(
  VkrResourceLoader *self,
  String8 name,
  VkrAllocator *temp_alloc,
  VkrResourceHandleInfo *out_handle,
  VkrRendererError *out_error) {

  VkrBitmapFontLoaderContext *ctx =
    (VkrBitmapFontLoaderContext *)self->resource_system;

  // 1. Allocate result structure (from arena pool if available)
  VkrBitmapFontLoaderResult *result = NULL;
  void *pool_chunk = NULL;

  if (ctx && ctx->arena_pool) {
    pool_chunk = vkr_arena_pool_acquire(ctx->arena_pool);
    Arena *arena = arena_create_from_buffer(pool_chunk, ctx->arena_pool->chunk_size);
    VkrAllocator result_alloc = {.ctx = arena};
    vkr_allocator_arena(&result_alloc);
    result = vkr_allocator_alloc(&result_alloc, sizeof(VkrBitmapFontLoaderResult),
                                  VKR_ALLOCATOR_MEMORY_TAG_STRUCT);
  } else {
    result = vkr_allocator_alloc(temp_alloc, sizeof(VkrBitmapFontLoaderResult),
                                  VKR_ALLOCATOR_MEMORY_TAG_STRUCT);
  }

  if (!result) {
    *out_error = VKR_RENDERER_ERROR_OUT_OF_MEMORY;
    return false_v;
  }

  MemZero(result, sizeof(VkrBitmapFontLoaderResult));
  result->pool_chunk = pool_chunk;

  // 2. Initialize parse state
  VkrBitmapFontParseState state = vkr_bitmap_font_parse_state_create(
    temp_alloc, temp_alloc, out_error);

  // 3. Parse .fnt file
  if (!vkr_bitmap_font_parse_fnt(&state, name)) {
    if (pool_chunk && ctx->arena_pool) {
      vkr_arena_pool_release(ctx->arena_pool, pool_chunk);
    }
    return false_v;
  }

  // 4. Load atlas texture via resource system
  VkrTextureHandle atlas = VKR_TEXTURE_HANDLE_INVALID;
  if (!vkr_bitmap_font_load_atlas(&state, temp_alloc, &atlas)) {
    *out_error = VKR_RENDERER_ERROR_RESOURCE_CREATION_FAILED;
    if (pool_chunk && ctx->arena_pool) {
      vkr_arena_pool_release(ctx->arena_pool, pool_chunk);
    }
    return false_v;
  }

  // 5. Build font result
  if (!vkr_bitmap_font_build_result(&state, atlas, &result->font)) {
    *out_error = VKR_RENDERER_ERROR_RESOURCE_CREATION_FAILED;
    // Unload atlas via resource system on failure
    VkrResourceHandleInfo atlas_info = {
      .type = VKR_RESOURCE_TYPE_TEXTURE,
      .as.texture = atlas,
    };
    vkr_resource_system_unload(&atlas_info, state.atlas_path);
    if (pool_chunk && ctx->arena_pool) {
      vkr_arena_pool_release(ctx->arena_pool, pool_chunk);
    }
    return false_v;
  }

  // 6. Store atlas path in result for cleanup during unload
  result->atlas_path = state.atlas_path;

  // 7. Return handle info
  result->success = true_v;
  out_handle->type = VKR_RESOURCE_TYPE_BITMAP_FONT;
  out_handle->loader_id = self->id;
  out_handle->as.custom = result;
  *out_error = VKR_RENDERER_ERROR_NONE;

  return true_v;
}
```

#### unload
```c
vkr_internal void
vkr_bitmap_font_loader_unload(
  VkrResourceLoader *self,
  const VkrResourceHandleInfo *handle,
  String8 name) {

  VkrBitmapFontLoaderContext *ctx =
    (VkrBitmapFontLoaderContext *)self->resource_system;

  if (handle->type != VKR_RESOURCE_TYPE_BITMAP_FONT) {
    log_warn("BitmapFontLoader: attempted to unload non-font resource");
    return;
  }

  VkrBitmapFontLoaderResult *result =
    (VkrBitmapFontLoaderResult *)handle->as.custom;

  if (!result) return;

  VkrFont *font = &result->font;

  // 1. Unload atlas texture via resource system
  if (font->atlas.id != 0 && result->atlas_path.str) {
    VkrResourceHandleInfo atlas_info = {
      .type = VKR_RESOURCE_TYPE_TEXTURE,
      .loader_id = VKR_INVALID_ID,  // Resource system will find the correct loader
      .as.texture = font->atlas,
    };
    vkr_resource_system_unload(&atlas_info, result->atlas_path);
  }

  // 2. Free glyph array
  if (font->glyphs.data) {
    array_destroy_VkrFontGlyph(&font->glyphs);
  }

  // 3. Free kerning array
  if (font->kernings.data) {
    array_destroy_VkrFontKerning(&font->kernings);
  }

  // 4. Return arena pool chunk if used
  if (result->pool_chunk && ctx->arena_pool) {
    vkr_arena_pool_release(ctx->arena_pool, result->pool_chunk);
  }
}
```

#### batch_load (optional optimization)
```c
vkr_internal uint32_t
vkr_bitmap_font_loader_batch_load(
  VkrResourceLoader *self,
  const String8 *paths,
  uint32_t count,
  VkrAllocator *temp_alloc,
  VkrResourceHandleInfo *out_handles,
  VkrRendererError *out_errors) {

  // For batch loading:
  // 1. Parse all .fnt files in parallel (via job system if available)
  // 2. Collect all unique texture paths from all fonts
  // 3. Batch load all textures via vkr_resource_system_load_batch(TEXTURE, ...)
  // 4. Build all font results with loaded atlas handles
  // 5. Return count of successfully loaded fonts

  // Simplified sequential implementation for initial version:
  uint32_t loaded = 0;
  for (uint32_t i = 0; i < count; i++) {
    if (vkr_bitmap_font_loader_load(self, paths[i], temp_alloc,
                                     &out_handles[i], &out_errors[i])) {
      loaded++;
    }
  }
  return loaded;
}
```

## Glyph Lookup Optimization

For efficient text rendering, provide O(1) glyph lookup:

```c
// In VkrFont struct (future enhancement):
VkrHashTable_uint32_t codepoint_to_glyph_index;

// Or use direct array for ASCII range:
uint16_t ascii_glyph_indices[128];  // Direct lookup for ASCII
// Use hashtable for non-ASCII codepoints

// Lookup function:
VkrFontGlyph* vkr_font_get_glyph(const VkrFont *font, uint32_t codepoint) {
  if (codepoint < 128) {
    uint16_t idx = font->ascii_glyph_indices[codepoint];
    if (idx != UINT16_MAX) {
      return &font->glyphs.data[idx];
    }
  }
  // Fall back to hashtable lookup for non-ASCII
  return vkr_font_get_glyph_hash(font, codepoint);
}
```

## Binary Cache Format (Future Enhancement)

For faster subsequent loads, implement a binary cache (`.vkf` format):

```c
// Header
#define VKR_FONT_CACHE_MAGIC   0x564B4654  // 'VKFT'
#define VKR_FONT_CACHE_VERSION 1

struct VkrFontCacheHeader {
  uint32_t magic;
  uint32_t version;
  uint32_t face_length;      // Length of face name
  uint32_t font_size;
  int32_t line_height;
  int32_t baseline;
  int32_t atlas_size_x;
  int32_t atlas_size_y;
  uint32_t glyph_count;
  uint32_t kerning_count;

};
```

## Resource System Integration

**Important:** All resource loading MUST go through the resource system API. The loader is never called directly by application code or other systems. The resource system dispatches to the appropriate loader based on resource type.

### Loading Flow

```
Application Code
      │
      ▼
vkr_resource_system_load(VKR_RESOURCE_TYPE_BITMAP_FONT, path, ...)
      │
      ▼
Resource System (finds registered loader for BITMAP_FONT type)
      │
      ▼
vkr_bitmap_font_loader_load() [internal callback]
      │
      ├──► Parse .fnt file
      │
      └──► vkr_resource_system_load(VKR_RESOURCE_TYPE_TEXTURE, atlas_path, ...)
                  │
                  ▼
           Texture Loader [internal callback]
```

### Texture Loading via Resource System

The bitmap font loader loads atlas textures through the resource system, NOT by calling the texture system directly:

```c
// CORRECT: Use resource system for texture loading
VkrResourceHandleInfo texture_info;
VkrRendererError tex_error;
if (vkr_resource_system_load(
      VKR_RESOURCE_TYPE_TEXTURE,
      atlas_path,
      temp_alloc,
      &texture_info,
      &tex_error)) {
  atlas_handle = texture_info.as.texture;
}

// INCORRECT: Do NOT call texture system directly
// vkr_texture_system_load(system, path, &handle, &error);  // NO!
```

### Return Value

The loader returns a `VkrResourceHandleInfo` with:
- `type = VKR_RESOURCE_TYPE_BITMAP_FONT`
- `loader_id` = assigned loader ID
- `as.custom` = pointer to allocated `VkrBitmapFontLoaderResult` containing `VkrFont`

The caller extracts the font data from `out_handle->as.custom`:

```c
VkrBitmapFontLoaderResult *result =
    (VkrBitmapFontLoaderResult *)font_info.as.custom;
VkrFont *font = &result->font;
```

## Usage Example

```c
// =============================================================================
// INITIALIZATION (once at startup)
// =============================================================================

// 1. Create loader context with dependencies
VkrBitmapFontLoaderContext font_ctx = {
  .job_system = job_system,      // Optional: for parallel batch loading
  .arena_pool = arena_pool,      // Optional: for result allocations
};

// 2. Create loader and register with resource system
VkrResourceLoader font_loader = vkr_bitmap_font_loader_create(&font_ctx);
vkr_resource_system_register_loader(&font_ctx, font_loader);

// =============================================================================
// LOADING (via resource system only)
// =============================================================================

// Single font load
VkrResourceHandleInfo font_info;
VkrRendererError error;
if (vkr_resource_system_load(
      VKR_RESOURCE_TYPE_BITMAP_FONT,
      string8_lit("assets/fonts/UbuntuMono21px.fnt"),
      temp_alloc,
      &font_info,
      &error)) {

  // Extract font from handle
  VkrBitmapFontLoaderResult *result =
      (VkrBitmapFontLoaderResult *)font_info.as.custom;
  VkrFont *font = &result->font;

  // Use font for text rendering...
  log_info("Loaded font '%s' with %u glyphs",
           font->face, font->glyphs.length);
}

// Batch load multiple fonts
String8 font_paths[] = {
  string8_lit("assets/fonts/UbuntuMono21px.fnt"),
  string8_lit("assets/fonts/NotoSans21px.fnt"),
};
VkrResourceHandleInfo handles[2];
VkrRendererError errors[2];

uint32_t loaded = vkr_resource_system_load_batch(
    VKR_RESOURCE_TYPE_BITMAP_FONT,
    font_paths, 2,
    temp_alloc,
    handles, errors);

log_info("Batch loaded %u/%u fonts", loaded, 2);

// =============================================================================
// UNLOADING (via resource system only)
// =============================================================================

// Unload single font
vkr_resource_system_unload(&font_info,
    string8_lit("assets/fonts/UbuntuMono21px.fnt"));
```

```
bitmap_font_loader.h
├── renderer/systems/vkr_resource_system.h
│   └── renderer/resources/vkr_resources.h (VkrFont, VkrFontGlyph, etc.)
├── memory/vkr_arena_pool.h (for arena pool in context)
├── core/vkr_job_system.h (for job system in context)
└── Forward declarations for VkrBitmapFontLoaderContext

bitmap_font_loader.c
├── bitmap_font_loader.h
├── containers/str.h (String8)
├── containers/vector.h (for parsing vectors)
├── containers/array.h (for glyph/kerning arrays)
├── core/logger.h
├── filesystem/filesystem.h
├── memory/vkr_allocator.h
├── memory/arena.h (for arena-based allocation)
└── renderer/systems/vkr_resource_system.h (for loading textures via resource system)
```

**Note:** The loader does NOT directly depend on `vkr_texture_system.h`. All texture loading goes through the resource system API.
