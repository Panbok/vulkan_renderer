# Mannequin credits

VKR's default mannequin is generated by `tools/blender/mannequin` from the
inputs pinned in `tools/blender/mannequin/sources.json`. It contains no Epic
Games content.

- **Body.** The realistic male body of Blender Studio's Human Base Meshes
  bundle v1.4.1, released under CC0 1.0 by Blender Studio. The helmet head,
  boots, shell design, textures, skeleton, skin weights, retargeting and
  materials are VKR's own.
- **Idle, backward, sidestep and crouch motion.** Retargeted from the
  100STYLE dataset (https://www.ianxmason.com/100style/), licensed under
  Creative Commons Attribution 4.0 International
  (https://creativecommons.org/licenses/by/4.0/). Credit: "The 100STYLE
  Dataset - Ian Mason". The clips were trimmed, looped, turned in place and
  retargeted with planted feet.
- **Forward walk, jog, run and jump motion.** Retargeted from the CMU
  Graphics Lab Motion Capture Database (http://mocap.cs.cmu.edu), subjects
  9, 13, 16 and 35. The data used in this project was obtained from
  mocap.cs.cmu.edu. The database was created with funding from NSF
  EIA-0196217.

A game that ships these animations must keep the 100STYLE credit above with
it, for example in its credits screen or bundled notices.
