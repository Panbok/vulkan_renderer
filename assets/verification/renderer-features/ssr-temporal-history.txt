User approved reading SSR history from the matching temporal producer through
existing GPU synchronization. No added images, waits, rays, or shader ABI fields.

same-queue write/read barriers and now pins matching transform submission identity.

The selector and publisher now use the stable projection. The tracing projection
remains jittered; previous-depth coefficients use only unchanged Z/W rows.

it was in flight, despite existing GPU ordering. Stable projection alone did not
reduce the captured flicker. Diagnostic frames 600..615 have valid/age/projection/
signature/radiance/publication/graph/transform checks all 1, completed=0, and no
selected SSR history. Temporary stderr instrumentation was removed before final
Release captures. Selected output and motion now demonstrate native accumulation.
