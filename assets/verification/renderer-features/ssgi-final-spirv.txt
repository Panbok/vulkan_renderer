# SSGI Release SPIR-V and Metal source review

Scope: generated Release artifacts only. No shader build or GPU execution was run.

## Commands

```sh
spirv-dis --raw-id build_release/renderer/generated/vulkan/packet.ssgi_depth_base.comp.spv -o /tmp/packet.ssgi_depth_base.comp.spvasm
spirv-dis --raw-id build_release/renderer/generated/vulkan/packet.ssgi_depth_mip.comp.spv -o /tmp/packet.ssgi_depth_mip.comp.spvasm
spirv-dis --raw-id build_release/renderer/generated/vulkan/packet.ssgi_trace.comp.spv -o /tmp/packet.ssgi_trace.comp.spvasm
spirv-dis --raw-id build_release/renderer/generated/vulkan/packet.ssgi_temporal.comp.spv -o /tmp/packet.ssgi_temporal.comp.spvasm
spirv-dis --raw-id build_release/renderer/generated/vulkan/packet.ssgi_composite.comp.spv -o /tmp/packet.ssgi_composite.comp.spvasm
spirv-dis --raw-id build_release/renderer/generated/vulkan/packet.deferred_lighting.comp.spv -o /tmp/packet.deferred_lighting.comp.spvasm
for f in build_release/renderer/generated/vulkan/packet.ssgi_*.comp.spv \\
         build_release/renderer/generated/vulkan/packet.deferred_lighting.comp.spv; do
  spirv-val --relax-block-layout "$f"
done
shasum -a 256 <each module> build_release/renderer/metal/library.metal \
  build_release/renderer/metal/library.slang.metal \
  .scratch/renderer-improvements-ssgi-spatial-release.log
```

All six `spirv-val --relax-block-layout` commands passed. Every module declares
`PhysicalStorageBufferAddresses` and `SPV_KHR_physical_storage_buffer`; the
composite natural root has its final reserved member at byte 404, so default
`spirv-val` rejects it for standard storage-buffer alignment. The relaxed-layout
mode is required for this generated physical-storage representation.

`VkrSsgiParams_natural` is 288 bytes in all parameterized modules. Its members
are projection/inverse/view at 0/64/128; dimensions at 192..204; depth-mip,
steps, history-valid, phase at 208/212/216/220; thickness/max-distance/
normal-bias/edge-fade at 224/228/232/236; temporal values 240..252;
previous-projection scalars 256..268; trace texel/extent scalars 272..284.
This proves the SSGI-only `sample_phase@220` and `normal_bias@232` fields.

## Metal generated source review

`build_release/renderer/metal/library.metal` contains all five Metal entries:
`vkr_metal_packet_ssgi_depth_base`, `_depth_mip`, `_trace`, `_temporal`, and
`_composite`, each with `[[buffer(0)]]`. Its generated `VkrSsgiParams` has the
same 288-byte field sequence above. The emitted deferred root preserves
`solar_disk_radiance`, then appends `direct_source`, `ssgi_enabled`, and
`ssgi_reserved`; it asserts a 192-byte Metal root. The five emitted native
root declarations match the host reflection records: 320, 320, 352, 400, and
448 bytes. The Release wrapper reported PASS in
`.scratch/renderer-improvements-ssgi-spatial-release.log`; this review did not
re-run native execution.
