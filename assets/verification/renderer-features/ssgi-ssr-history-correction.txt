most nine additional history reads per half-resolution pixel. Existing budgets
and stationary settling periods remain unchanged.

Changes
SSGI motion is unjittered, but history resides on the raster grid. Both native
shaders now add previous-minus-current jitter UV before lookup. Two unused
parameter floats at offsets280/284 now carry those offsets; parameters remain
288bytes, with no root growth. FSR uses its active phase count, MetalFX uses
eight phases, and no-TAA uses zero offsets. Four bilinear taps independently
validate depth/identity and resolve RGB with bilinear*confidence weights.
The exact shared motion producer may remain in flight: existing Metal event
ordering / Vulkan same-queue barriers protect reads. Other producers must be
complete. Tuple coherence, last-reader retirement and output-reuse completion
proofs remain; Vulkan now checks exact transform instance and submit value too.

SSR formerly normalized history RGB by blended coverage. With current coverage
.05, history coverage1 and weight.85, effective old-RGB retention became .99125.
Supported normalized RGB retention is now capped at the intended temporal weight.
Coverage blending and empty-neighborhood decay formulas are unchanged. Sparse
hits admit more fresh-sample noise; this bounds a long trail without increasing
reads/storage. Reflected-object identity is still not retained, so this does
not establish complete ghost elimination in every scene.
