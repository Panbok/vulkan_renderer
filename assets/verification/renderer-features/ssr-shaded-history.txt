SSR receiver-shaded history — 2026-09-09

Decision and implementation
User approved moving material/AO shading into the existing half-resolution SSR
history, with up to 17 additional texture accesses per pixel, no additional
images/rays, and possible material/coat/mirror boundary softness. History now
contains shaded radiance and independent coverage. Trace/raw remains incoming
radiance. Current spatial radiance and its clamp bounds receive the same selected
receiver weight before temporal accumulation. Composite subtracts the exact
current probe contribution and adds shaded history without another BRDF/GTAO
multiplication. Depth/identity rejection, jitter reprojection, four validated
history taps, empty-frame fade and GPU completion/producer rules remain.

The weight includes GGX or anisotropic material energy, horizon/specular AO,
directional GTAO cone, coat factor for selected coats and sheen allocation for
uncoated bases. It excludes authored IBL gain. The exact old probe term retains
that gain. Composite now uses deferred's base-normal roughness footprint at
textured coat boundaries. Coat subtraction uses raw authored coat roughness and
the GTAO policy actually written by each backend's deferred pass. Metal applies
the base GTAO cone; Vulkan's existing coat probe path does not. That pre-existing
native policy gap remains recorded rather than silently changing deferred output.
Vulkan GTAO reads now use normalized sampling, matching deferred and safely
sampling the disabled 1x1 sentinel instead of an out-of-bounds full-size Load.

Budgets and ownership
No new persistent images, rays, or traversal steps. Approved source-access ceiling
is 92, with at most 17 added on any branch. Reviewed Metal maximum is 91 because
center clearcoat is retained. Shader accesses are not physical texel-fetch counts.
Temporal appends frame/albedo/GTAO/sheen/anisotropy references: Metal root 464 bytes;
Vulkan 400 bytes, including explicit tail padding. Metal reserves three additional
512-byte upload cells (1536 bytes per active SSR frame, 592 bytes of added payload).
Vulkan reuses the existing frame root and adds 32 upload bytes. Existing per-slot
upload ownership and completion retirement remain. Graph reads 17–20 declare the
new existing-image dependencies; GTAO 18 is conditional with native fallback.
SSR content signatures already include GTAO controls and radiance revisions.
Capture ssr_reflection version 3 denotes shaded RGB. Raw SSR retains version 2.
